# Support

## Getting Help

Use GitHub issues for:

- reproducible bugs
- documentation gaps
- feature requests tied to the current project scope

Use GitHub discussions if they are enabled later for:

- setup questions
- architecture discussion
- usage advice

## Before Opening an Issue

- read the `README.md`
- check `CONTRIBUTING.md`
- confirm whether your setup matches the documented local or compose workflow
- include logs, configuration context, and reproduction steps with secrets removed

## Scope

This project is maintained as a self-hosted, experimental agentic search backend.
Support is best-effort. Turnkey production support is out of scope.
