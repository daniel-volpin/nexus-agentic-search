# Code of Conduct

## Our Standard

This project aims to be useful, direct, and respectful.

Examples of behavior that contribute to a healthy environment:

- giving constructive technical feedback
- assuming good intent while discussing trade-offs
- keeping criticism focused on code, design, and evidence
- documenting decisions clearly for other contributors

Examples of unacceptable behavior:

- harassment, personal attacks, or discriminatory language
- intentionally disruptive behavior
- publishing private information without permission
- bad-faith security disclosure in public channels

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, and other contributions that do not align with this code of conduct.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer through the repository owner profile with relevant context.
